# 3D Supermarket Simulator — Android
Unity LTS starter production project generated from the supplied Master Development Specification.

This package is a real Unity project source foundation. It contains working C# domain/runtime systems for:
- product definitions and batches
- inventory and shelf state
- atomic checkout transactions
- customer state machine
- employee task state machine
- supplier/order state
- incidents
- store progression
- versioned JSON save/load with checksum
- deterministic daily seed
- basic first-person player interaction
- Android-ready input abstraction hooks

It does NOT claim to contain final AAA art, all prefabs, audio, or an already-compiled APK. Open it in a supported Unity LTS Editor, create the required prefabs/scenes, then build Android.
